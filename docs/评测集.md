## 1. 数据字典（评测集依据）

### 1.1 表清单

| 表名 | 主键 | 行数 | 说明 |
|---|---|---|---|
| ads_trade_overview_di | dt | 7 | 全局日汇总 |
| ads_channel_conversion_di | dt, channel | 21 | 渠道转化（3 渠道 × 7 天） |
| ads_region_gmv_di | dt, province | 35 | 地域 GMV（5 省 × 7 天） |
| ads_product_sales_rank_di | dt, product_id | 21 | 商品销售排行（3 商品 × 7 天） |

### 1.2 字段定义

**ads_trade_overview_di**：`dt`(date), `total_order_cnt`, `paid_order_cnt`, `total_gmv`, `paid_user_cnt`

**ads_channel_conversion_di**：`dt`(date), `channel`(varchar), `channel_name`(varchar), `visit_uv`, `order_cnt`, `paid_order_cnt`, `gmv`, `order_conversion_rate`, `pay_conversion_rate`

**ads_region_gmv_di**：`dt`(date), `province`(varchar), `province_name`(varchar), `region`(varchar), `order_cnt`, `paid_order_cnt`, `paid_user_cnt`, `gmv`

**ads_product_sales_rank_di**：`dt`(date), `product_id`(varchar), `product_name`(varchar), `category_name`(varchar), `sale_cnt`, `sale_amount`

### 1.3 维度取值（Ontology 建模必读）

- **渠道** `channel → channel_name`：`app→APP`、`miniapp→小程序`、`web→网页`
- **地域** `region`：华东（江苏/上海/浙江）、华北（北京）、华南（广东）
- **省份** `province → province_name`：JS→江苏、SH→上海、ZJ→浙江、BJ→北京、GD→广东
- **类目** `category_name`：办公家具、电脑外设
- **商品** `product_id → product_name`：p0→机械键盘、p1→4K显示器、p2→人体工学椅

## 2. 评测题目（15 题）

### 难度档位

| 档位 | 题号 | 考察点 |
|---|---|---|
| 简单 | 1~5 | 单表单条件 / 单聚合 / DISTINCT |
| 中等 | 6~10 | 排序 / TopN / 比例计算 / 条件聚合 |
| 复杂 | 11~15 | 跨日聚合 / 分组 TopN / 多表关联 / 占比 |

### 简单档

**Q1** 10月19日当天的总GMV是多少？

```sql
SELECT total_gmv FROM mall_dw.ads_trade_overview_di WHERE dt = '2026-10-19';
```

预期结果：`53042.41`

---

**Q2** 近7天累计支付订单数是多少？

```sql
SELECT SUM(paid_order_cnt) AS total_paid FROM mall_dw.ads_trade_overview_di;
```

预期结果：`69`

---

**Q3** 10月19日小程序渠道的GMV是多少？

```sql
SELECT gmv FROM mall_dw.ads_channel_conversion_di WHERE dt = '2026-10-19' AND channel_name = '小程序';
```

预期结果：`15604.97`

**Q4** 华东地区有哪些省份？

```sql
SELECT DISTINCT province_name FROM mall_dw.ads_region_gmv_di WHERE region = '华东' ORDER BY province_name;
```

预期结果：`江苏`、`上海`、`浙江`

**Q5** 电脑外设类目下有哪些商品？

预期结果：`4K显示器`、`机械键盘`

### 中等档

**Q6** 10月19日各渠道的支付转化率分别是多少？按转化率从高到低排序。

```sql

FROM mall_dw.ads_channel_conversion_di
WHERE dt = '2026-10-19'
ORDER BY pay_conversion_rate DESC, channel_name;
```

预期结果：`APP 0.1000`、`小程序 0.1000`、`网页 0.0750`

**Q7** 10月19日GMV最高的省份是哪个？

**Q14** 近7天里总GMV最高的是哪一天？

```sql
SELECT dt, total_gmv
FROM mall_dw.ads_trade_overview_di

```

预期结果：`2026-10-16 66184.50`

---

**Q15** 10月19日各渠道GMV占当天总GMV的比例分别是多少？

```sql
SELECT c.channel_name, ROUND(c.gmv / t.total_gmv, 4) AS ratio
FROM mall_dw.ads_channel_conversion_di c
JOIN mall_dw.ads_trade_overview_di t ON c.dt = t.dt
WHERE c.dt = '2026-10-19'
ORDER BY ratio DESC;
```

预期结果：`APP 0.3832`、`网页 0.3226`、`小程序 0.2942`

## 3. 评分标准

- **SQL 等价性**：Agent 生成的 SQL 执行结果与预期结果一致（数值、行序不敏感，集合语义一致即可）判对。
- **表/字段合法性**：Agent 生成的 SQL 涉及的表名、字段名必须全部落在 Ontology 白名单内（由 JSqlParser 提取比对，幻觉归零）。
- **准确率口径**：`准确率 = 判对题数 / 15`。
- **六层指标**（交测试 Agent 时上报）：准确率、表命中率、字段命中率、平均延迟、SQL 语法通过率、闸门拦截率。

## 4. 验收基线

- 简单档（Q1~Q5）准确率目标：100%
- 中等档（Q6~Q10）准确率目标：≥ 80%（4/5）
- 复杂档（Q11~Q15）准确率目标：≥ 60%（3/5）
- 整体准确率目标：≥ 80%（12/15）
