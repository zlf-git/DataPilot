# Ticket 13：前端（问数页 + 指标管理 + 元数据页 + 闸门配置）

## 目标
React 前端从 0 建，问数页链路透明展示，元数据页必需（含字段白名单编辑）。

## 背景
来自 F-07 + A7（Spec §3 阶段③）+ Spec §2.4。审计 P1#9/#16/#17：预估 2.5 天、依赖补 11、write-enabled 联调前置。

## 修改范围
- 新增 `frontend/`（React18+Vite5+AntD5），四页面

## 任务
1. 问数页调 /api/ask 透明展示 ir/sql/gates/rows/**answer/reportHtml（依赖 Ticket 11 的三字段）**
2. 指标管理页业务自助维护 metric_def
3. 元数据页（必需）只读展示 + 字段白名单编辑
4. 闸门配置页管理员调阈值
5. **联调前置（审计 P1#17）**：三页的 PUT 接口依赖 `datapilot.metadata.write-enabled=true`，联调时先开，否则页面 PUT 全被拒

## 验收标准
页面可操作，白名单有维护入口不用改代码；问数页能展示 answer + 报告。

## 测试要求
前端冒烟（手动），断言问数页调通 /api/ask 并展示链路（含 answer/reportHtml）。只测外部行为。

## 依赖
Ticket 01 + Ticket 01b + Ticket 11（问数页展示 answer/reportHtml 需 11 的三字段）

## 预估
2.5 天

## 不包含
- AntV G2 图表
- 登录 UI（鉴权 Ticket 14）
