# Ticket 04：时间窗口（半开区间）

## 目标
QueryIr 加 timeRange，生成器展开半开区间 `dt > ? AND dt <= ?`（禁 BETWEEN），anchor 缓存 RecallStep。

## 背景
来自 B2（Spec §3 阶段②）。审计 P0#1：BETWEEN 是闭区间，不可能「不含第 8 天」，必须改 `dt > ? AND dt <= ?`。

## 修改范围
- `ir`：TimeRange
- `RecallStep`：缓存 anchor（max-7d / max 两参数）
- `IrToSqlConverter`：timeRange→`dt > ? AND dt <= ?`
- `src/main/resources/stub_ir/`：更新 q2/q11-q14（补 timeRange）

## 任务
1. QueryIr 加 timeRange{relativeWindow,days,anchor}
2. RecallStep 查 MAX(dt) 并缓存（一次问数只查一次），算好两参数 `max-7d`、`max`
3. 生成器展开 `dt > ? AND dt <= ?`（**全文禁 BETWEEN**，BETWEEN 闭区间会取 10-12~10-19 共 8 天）
4. 更新 stub_ir：q2/q11-q14 补 `timeRange{relativeWindow, days:7}`（stub IR 是 01c 生成的基础版，本票补 timeRange 字段）

## 验收标准
Q2/Q11-Q14 生成半开区间，anchor 取 MAX(dt) 非 now()，结果 7 行（10-13~10-19），不取 8 天。

## 测试要求
集成测试：打 Q2/Q11-Q14，**断言 SQL 含 `dt >` 且参数为 10-12/10-19、结果 7 行**。只测外部行为。

## 契约（01c QA 回填）

1. **Q2 现在「值对」是假象**：`q2.json` 的 IR 里没有 timeRange，返回 69 只是因为 `ads_trade_overview_di` 恰好只有 2026-10-13~10-19 七天数据。数据一延长，Q2/Q11/Q12/Q13/Q14 全部偏离，而 stub 仍「命中」。本票必须回填这 5 条的 `timeRange{relativeWindow, days:7}`。
2. anchor 取 `MAX(dt)` 不取 `now()`，半开区间 `dt > ? AND dt <= ?`，参数是 `max-7d` / `max`（即 10-12 / 10-19），全文禁 BETWEEN。
3. 本票完成后，`qa/eval_expectations.json` 里 Q2/Q11~Q14 的 `caliberPending` 才能删；删之前 `qa/e2e_stub.py` 会一直打出「口径待办」，别当噪音忽略。

## 落地记录（2026-10-21）

- `ir/TimeRange.java`：`relativeWindow`（仅 `LAST_N_DAYS`，兼容 `LAST_DAYS`/`RECENT_DAYS` 别名）+ `days`(1~366) + `anchor`（解析结果回填）。
- `sql/TimeAnchorProvider.java`：`SELECT MAX(dt) FROM <表>`（agent_ro，表名过 `^[a-z_][a-z0-9_]*$` + 白名单校验），Caffeine TTL 60s 按表缓存；查不到锚点显式抛错，**不回退 now()**。
- `RecallStep`：召回后对候选表 `prefetchQuietly` 预热锚点（失败只 warn），一次问数只查一次库。
- `IrToSqlConverter`：`dt > ? AND dt <= ?`，参数 `anchor-days` / `anchor`；与 `dt` 过滤并存时显式拒绝；`relativeWindow` 不在白名单、`days` 越界、`anchor` 与 `MAX(dt)` 不一致均显式报错。
- stub：q2/q11/q12/q13/q14 补 `timeRange{LAST_N_DAYS,7}`；`qa/eval_expectations.json` 删掉这 5 题的 `caliberPending`，改为 `window{days,from,anchor}` 断言。
- 验收：13/15 可用保持，Q2/Q11~Q14 全 `OK` 且 window 断言通过（SQL 含 `dt > ?`/`dt <= ?`、参数 2026-10-12/2026-10-19、IR 回填 anchor=2026-10-19）；`days=3` 探针得 157702.85 = 半开 3 天（若误用 BETWEEN 会是 223887.35 / 4 天）。
