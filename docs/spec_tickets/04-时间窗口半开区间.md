# Ticket 04：时间窗口（半开区间）

## 目标
QueryIr 加 timeRange，生成器展开半开区间 `dt > ? AND dt <= ?`（禁 BETWEEN），anchor 缓存 RecallStep。

## 背景
来自 B2（Spec §3 阶段②）。审计 P0#1：BETWEEN 是闭区间，不可能「不含第 8 天」，必须改 `dt > ? AND dt <= ?`。

## 修改范围
- `ir`：TimeRange
- `RecallStep`：缓存 anchor（max-7d / max 两参数）
- `IrToSqlConverter`：timeRange→`dt > ? AND dt <= ?`
- `src/main/resources/stub_ir/`：更新 q2/q11-q14（补 timeRange）

## 任务
1. QueryIr 加 timeRange{relativeWindow,days,anchor}
2. RecallStep 查 MAX(dt) 并缓存（一次问数只查一次），算好两参数 `max-7d`、`max`
3. 生成器展开 `dt > ? AND dt <= ?`（**全文禁 BETWEEN**，BETWEEN 闭区间会取 10-12~10-19 共 8 天）
4. 更新 stub_ir：q2/q11-q14 补 `timeRange{relativeWindow, days:7}`（stub IR 是 01c 生成的基础版，本票补 timeRange 字段）

## 验收标准
Q2/Q11-Q14 生成半开区间，anchor 取 MAX(dt) 非 now()，结果 7 行（10-13~10-19），不取 8 天。

## 测试要求
集成测试：打 Q2/Q11-Q14，**断言 SQL 含 `dt >` 且参数为 10-12/10-19、结果 7 行**。只测外部行为。
