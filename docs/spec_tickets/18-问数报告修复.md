# Ticket 18：问数报告修复（图表空白 + 单指标只有一个数）

## 目标
用户上传的截图里，报告是一块**空白图** + 一张只有一列的表，底部孤零零一行 `gmv_channel`。
两件事同时错：
1. 图从来没画出来过（不是偶发，是必现）；
2. 单指标被画成柱状图，视觉上像「报告坏了」。
本票把这两个问题分别修掉，并把「字符串里有 echarts」这种**假判据**换成「浏览器里真的画出来了」。

## 背景（根因）
`ReportStep` 把 ECharts 挂在 `https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js`。
本机实测：

```
curl https://cdn.jsdelivr.net/... → exit 35（SSL connect error），0 字节
```

于是 `window.echarts === undefined`，`if (window.echarts && el) {...}` 直接跳过，
`<div id="chart">` 是一块 380px 的空盒子。**表格还在，所以看起来像「报告只有一行字」**。

为什么一直没被发现：Ticket 11 的验收判据是 `reportHtml 含 echarts` 与
`series 长度 = rows 长度` —— 两条都只查**字符串**。CDN 拿不到时字符串照样有 `echarts`、`series` 照样对，
所以 142 项 explain 验收、40 项冒烟全绿，而用户看到的报告一直是空白的。
`ReportStep` 注释里还写着「无网时图表区空白、表格仍在，这是明确的降级路径」——
把**环境缺陷**当成降级设计写进了代码注释，这是本票最值得记的一条。

## 修改范围
- `agent/step/ReportStep.java`（重写渲染：本地 echarts、metric 卡片、口径区、SQL 区）
- `src/main/resources/static/report-assets/echarts.min.js`（新增，5.5.0，1029203 字节，Apache-2.0 自带许可头）
- `deploy/dp-web/nginx.conf`（新增入库文件：`/report-assets/` 反代，`^~` 前缀）
- `frontend/src/index.css`（report-frame 560 → 680px）
- `frontend/src/pages/AskPage.jsx`（无改动，仅确认 iframe 结构）
- `qa/verify_report.cjs`（新增，17 项浏览器渲染判据）
- `qa/smoke_frontend.cjs`（本地 server 代理 `/report-assets`；报告判据升级为「真的渲染了」；`check()` detail 支持对象）
- `src/test/java/.../ReportStepTest.java`（9 例，新增 4 例）
- 截图：`docs/screenshots/report_metric.png`、`report_bar.png`

## 任务
1. **图表库本地化**：`/report-assets/echarts.min.js` 同源提供，报告不再引用任何 `http(s)://` 外链。
2. **metric 走卡片**：`chartType=metric` 不画图，渲染大数字卡片（值 + 指标 id），不再留空图容器。
3. **报告补全**：`口径与查询条件`（指标中文名/口径表达式/数据源表/过滤条件/时间窗口/结果规模/闸门结论）、
   `结果明细`、`生成的 SQL`（折叠，带绑定参数）、生成时间。指标口径从 `metric_def` 取，取不到降级成 metricId。
4. **nginx**：`location ^~ /report-assets/` 反代到后端。必须是 `^~` —— 下面那条 `~* \.(js|css|...)$`
   是正则 location，**正则优先于普通前缀**；写成 `location /report-assets/` 时 `echarts.min.js`
   仍被正则接走、按静态文件找 → 404（实测过，见「偏差与踩坑」）。
5. **判据升级**：`verify_report.cjs` 用真实浏览器打开 iframe，断言
   `window.echarts` 存在、canvas 尺寸非零、`canvas.toDataURL()` 长度 > 3000（不是白板）、
   metric 场景只有卡片没有 `#chart`、全程无外网请求。
6. `smoke_frontend.cjs` 里那句「报告 iframe 含 echarts」保留（字符串层），但**新增**渲染层断言：
   单指标必须出现 `.card` 且值为 `15604.97`。

## 偏差与踩坑（如实记录）

1. **metric 场景不再有 `#chart`**：`option` 仍然生成（`series` 契约靠它），只是页面不渲染图。
   这是有意的取舍：一根柱子上顶一个数没有信息量。`series 长度 = rows 长度` 的判据完好。
2. **`location /report-assets/` 404**：第一版写成普通前缀，实测 `8080/report-assets/echarts.min.js`
   返回 404（被正则 location 抢走）。改 `^~` 后 200 / 1029203 字节。
3. **`page.frames()` 里有多个 `about:srcdoc`**：上一轮被替换的报告 iframe 还没被回收，
   `find()` 取第一个会拿到**空 frame**，于是误判「报告没渲染」（冒烟第一版就踩了）。
   改成遍历并挑「有内容」的那个。
4. **`ReportStepTest.reportCarriesTraceIdAndChartType` 依赖字面 `bar`**：meta 行原本只写中文「柱状图」，
   会把这条已验收的断言打红。改成 `柱状图（bar）` —— 中文给人看、英文留给 trace 对照，两边都要。
5. **`Check.detail` 打印 `[object Object]`**：冒烟脚本的 `check()` 用 `' :: ' + detail` 拼字符串，
   对象一律变 `[object Object]`，失败时完全看不出取到了什么。改成非字符串 JSON 化。
6. **echarts 1MB 入库**：不放 `frontend/public`（那会被 dist 构建带走两份），放后端 `static`，
   由 nginx 反代统一入口。代价是仓库多 1MB 二进制，收益是「离线也能画图」。

## 测试要求
只测外部行为：报告 HTML 的字符串契约（单测）+ 浏览器里真实渲染结果（verify_report）。
「图有没有画出来」这件事不再用 `contains('echarts')` 代替。
