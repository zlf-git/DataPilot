# Ticket 01：主链路骨架打通（Spring AI 替换 + AgentEngine + AskController）

## 目标
用 Spring AI 替换手写 LLM 客户端，立起 AgentEngine 编排链 + AskController + 最简 IR→SQL→执行 + AskResponse 契约，StubLlmClient 跑通 Q1。

## 背景
来自开发Spec §2.3 缺失项、§4.1 包结构、§4.2 编排链、§4.4 接口关系、F-06 LLM集成。主链路现在是断的（RewriteStep/RecallStep 无人调用，无 Controller 无 Engine）。审计 P0#2/#8：钉死抽象层 + 定义 AskResponse 契约。

## 修改范围
- `llm` 包：LlmClient 薄封装接口 + StubLlmClient（provider=stub）+ DeepSeekLlmClient（Spring AI ChatClient）
- `agent` 包：AgentEngine + 6 Step 骨架
- `controller`：AskController + AskResponse DTO
- `sql`：最简 IrToSqlConverter + StarRocksSqlExecutor
- `pom.xml`：spring-ai 依赖
- `application.yml`：datapilot.llm 配置块（provider=stub/deepseek）
- `src/main/resources/stub_ir/q1.json`：桩 LLM 的 Q1 固定 IR

## 任务
1. pom 引入 spring-ai-bom + starter-model-openai
2. **抽象层钉死一层**（审计 P0#2：01 与 08 不能两套并存）：定义 `LlmClient` 薄封装接口（入 system+user prompt，出结构化结果）；两个实现：
   - `StubLlmClient`：`@ConditionalOnProperty(name="datapilot.llm.provider", havingValue="stub")`，读 `src/main/resources/stub_ir/q{n}.json` 按 question 匹配返回固定 IR，**并返回固定 usage（in 500 / out 100）保证 cost>0 可验（Ticket 09 判据）**
   - `DeepSeekLlmClient`：`@ConditionalOnProperty(havingValue="deepseek")`，用 Spring AI `ChatClient` 包 DeepSeek（base-url 指向 DeepSeek OpenAI 兼容端点）
   - **Qwen 等其余真实 provider 由 Ticket 08 的工厂产出，本票不碰（08 工厂只产出真实 provider，不产出 stub）**
3. 立 AgentEngine 编排链（Rewrite→Recall→Prompt→LLM→[闸门空实现]→SQL→执行→返回），6 Step 骨架
4. 最简 IrToSqlConverter：**单指标聚合 + 单表 + 单条件等值 filter（EQ，日期字面量做类型转换）**——Q1 标准 SQL 是 `SELECT total_gmv ... WHERE dt = '2026-10-19'`，缺 filter 能力会生成 7 天合计 390001.84 而非 53042.41
5. StarRocksSqlExecutor（JdbcTemplate + agent_ro@9030）
6. AskController：POST /api/ask，返回 AskResponse
7. **定义 AskResponse 契约**（审计 P0#8：06b/13/11 都引用它，只在本票定义、后续只引用不改）：
   `AskResponse{ traceId, question, ir, sql, params[], gates[], rows[], costMs, answer, chartType, reportHtml }`
   - 本票 answer/chartType/reportHtml 填占位空值，Ticket 11 填充
8. RestClient 超时（connect 3s / read 30s）+ 失败重试 1 次，超时返回「模型响应超时，请重试」不抛 500（Spec §4.5）

## 验收标准
`mvn spring-boot:run` 起（provider=stub），`POST /api/ask`「10月19日总GMV是多少」返回 AskResponse：rows 含 53042.41、SQL 命中 ads_trade_overview_di 且含 `dt = ?`（不是 7 天合计）。

## 测试要求
集成测试：StubLlmClient 打 `/api/ask`，断言 rows 含 53042.41、SQL 含 `dt = ?`、AskResponse 字段齐全。只测外部行为。
