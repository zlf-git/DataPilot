## 二、P0：打通主链路 CDC→Kafka→Flink→Paimon→StarRocks

1. MySQL 建订单业务库表 + 造测试数据（binlog 已开，ROW 格式）
2. Kafka 建 order-cdc topic
3. Flink 提交 MySQL CDC → Kafka 任务
4. Flink 提交 Kafka → Paimon 表任务
5. StarRocks 建 Paimon Catalog，外部表查询
6. 端到端数据验证

## 三、P1：打通监控链路 Prometheus + Grafana

Grafana 只是可视化面板，本身不采集数据。要监控容器/宿主机资源需补监控栈：

- Prometheus：采集 + 存储时序指标
- node-exporter：宿主机 CPU/内存/磁盘/网络
- cadvisor：Docker 容器指标
- 组件 exporter：MySQL / Kafka / Flink / StarRocks

## 四、P2：数据权限与调度接入

- Ranger 配置 HDFS/Hive 插件
- Dinky 注册 Flink 集群 + 数据源
- DolphinScheduler 编排任务
- go-view 接入 StarRocks 数据
