## 二、P0 主链路（已完成 ✅）

1. ✅ MySQL 建 cdc_source.orders + 造 75 条抖音订单（12 字段）
2. ✅ Kafka 建 ods_douyin_order_cdc topic
3. ✅ job1 MySQL CDC → Kafka
4. ✅ job2 Kafka → Paimon ODS（湖）
5. ✅ job3 ODS → DWD（湖）
6. ✅ job4 DWD → DWS×3（湖）
7. ✅ job5 DWS → 双写 Paimon ADS×4（湖冷存储）+ StarRocks ADS×4（仓热查询）

**关键卡点已解决**：StarRocks allin1 的 BE 注册为 127.0.0.1 导致 connector Stream Load 连错，用官方 feproxy 8080 端口方案解决。
