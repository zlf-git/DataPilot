## 二、P0 主链路（已完成 ✅，全流版）

1. ✅ MySQL 建 cdc_source：orders 事实表（只存外键）+ dim_product/dim_channel/dim_province 维度表 + 造 75 条订单
2. ✅ Kafka 建 ods_douyin_order_cdc（3 分区）+ ods_dim_*_cdc（维度表）
3. ✅ job1 MySQL CDC → Kafka（4 表一表一 topic，sink 按主键 hash 分区）
4. ✅ job2 Kafka → Paimon ODS + DIM（湖）
5. ✅ job3 ODS → DWD（湖，事实表只存外键）
6. ✅ job4 DWD → DWS×4（湖，lookup join 拼维度 + trade_overview 流式维护 + State TTL 7d + checkpoint 60s）
7. ✅ job5 DWS → StarRocks×4（流作业，读 DWS changelog 直写 SR 主键表 upsert）
8. ✅ job6 DWS → StarRocks×4（批作业，从 DWS 全量重建 SR 的补数/回刷入口）

**关键卡点已解决**：
- StarRocks allin1 的 BE 注册为 127.0.0.1 导致 connector Stream Load 连错，用官方 feproxy 8080 端口方案解决（load-url 用 `sr-ai-analysis:8080`）。
- 中文双重编码：`docker exec -i mysql < file` 默认 latin1 解读 stdin，须加 `--default-character-set=utf8mb4`。
- Flink lookup join：Paimon 表无隐式 proc_time，须子查询包装 `(SELECT *, PROCTIME() AS proc_time FROM dwd_orders)`。

## 三、P1：可视化大屏 + 监控栈（已完成 ✅ 2026-10-21）

落地记录见 `P1-可视化与监控-落地记录.md`。

1. ✅ **经营大屏**（`http://localhost:8080/dashboard`）：4 个 KPI 卡片 + 近 7 日 GMV 趋势 + 渠道转化 + 地区排行 + 商品 TOP，30 秒轮询刷新
   - 数据走新增的 `GET /api/dashboard/{summary,trade-trend,channel,region,product}`（只读，SQL 写死只碰 `mall_dw.ads_*`）
   - **没用 go-view**：本机只有它的静态 dist，编辑器登录要 `go-view-server`（未部署、镜像拉不到），打开就是登录页进不去；改成 DataPilot 自建页面（React + 手写 SVG，零新依赖），8080 端口复用给 nginx 容器 `dp-web`
2. ✅ **监控栈**：Prometheus 2.54 + node-exporter + kafka-exporter + StarRocks FE/BE 原生 `/metrics` + Flink 内置 prometheus reporter（9249），**7/7 抓取目标 up**
3. ✅ **Grafana 面板**：数据源与面板全走 provisioning（JSON 进 Git），8 个 panel：宿主机 CPU/内存/磁盘、抓取目标健康、Kafka 各 topic 写入速率、StarRocks FE QPS + BE CPU、Flink JM/TM 堆内存
4. ⚠️ **cadvisor 未接**：官方镜像只在 gcr.io，本机 gcr 直连超时、三个镜像源都不通（daocloud 对 gcr 转发 403、1ms/rat.dev DNS 不通、Docker Hub 无此包），容器级 CPU/内存暂缺
