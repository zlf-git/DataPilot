> F-07 定义前端页面与接口契约。核心设计：问数页**透明展示整条链路**（IR → SQL → 闸门状态 → 结果），不搞黑盒，演示时能把「语义层约束 + 五道闸门」看得一清二楚。

---

## 1. 页面清单

| 页面 | 角色 | 功能 |
|---|---|---|
| 问数页 `/ask` | 所有人 | 自然语言问数 + 链路透明展示 |
| 指标管理页 `/metrics` | 业务 | `metric_def` 自助 CRUD |
| 闸门配置页 `/gate-config` | 管理员 | `gate_config` 阈值调整 |
| 元数据页 `/metadata`（可选） | 管理员 | 表/字段白名单维护 |

---

## 2. 问数页（核心）

### 2.1 交互流程

```
输入问题 → POST /api/ask → 后端跑完整链路
  → 返回 { question, ir, sql, rows, gates[], costMs }
  → 前端分区展示
```

### 2.2 展示分区（透明化亮点）

| 分区 | 展示内容 | 作用 |
|---|---|---|
| ① 问题 | 原始问题 | 对齐上下文 |
| ② IR | 生成的 IR JSON（可折叠） | 展示「结构化中间态」，不是裸 SQL |
| ③ SQL | 由 IR 转出的受控 SQL | 展示参数化绑定后的最终 SQL |
| ④ 闸门 | 五道闸门逐条状态（通过 ✅ / 拦截 ⛔ + 原因） | 展示安全链路 |
| ⑤ 结果 | 结果表格 / 无数据提示 / 告警 | 最终答案 |

### 2.3 示例（评测集 Q6）

用户输入「10月19日各渠道的支付转化率分别是多少？按从高到低排序」后，页面展示：

- **IR**：`{ metrics:[{metricId:"支付转化率"}], dimensions:[{field:"channel_name"}], filters:[{field:"dt",op:"=",value:"2026-10-19"}], orderBy:[...] }`
- **SQL**：`SELECT channel_name, pay_conversion_rate FROM ads_channel_conversion_di WHERE dt = ? ORDER BY pay_conversion_rate DESC`
- **闸门**：存在性 ✅ / 权限 ✅ / 代价 ✅ / 语法 ✅ / 结果自检 ✅
- **结果**：表格三行（APP 0.1000 / 小程序 0.1000 / 网页 0.0750）

## 3. 指标管理页（业务自助）

- 列表：展示 `metric_def` 全部指标（名称、口径 SQL、归属部门、负责人、状态）。
- 新增/编辑：业务填指标名、同义词、口径 SQL、归属部门、可用维度。
- 规则：同 `metric_name` 只允许一个启用中（同词唯一），新增同名词需停用旧定义。
- 无删除硬删，只停用（`status` 置停用），保留审计。

---

## 4. 闸门配置页（管理员）

- 展示 `gate_config` 当前值：`max_join` / `max_metric` / `max_limit` / `max_rows`。
- 调整阈值：`join≤2→3`、`limit≤1000→5000` 等。
- 记录修改人 `updated_by` + 修改时间。
- 业务用户无入口，进入即 403。

---

## 5. REST API 契约

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/api/ask` | 问数，返回 `{question, ir, sql, rows, gates[], costMs}` | 所有人 |
| GET | `/api/metrics` | 指标列表 | 所有人 |
| POST | `/api/metrics` | 新增指标 | 业务 |
| PUT | `/api/metrics/{id}` | 编辑指标 | 业务 |
| PUT | `/api/metrics/{id}/disable` | 停用指标 | 业务 |
| GET | `/api/gate-config` | 闸门配置 | 管理员 |
| PUT | `/api/gate-config/{key}` | 调整阈值 | 管理员 |
| GET | `/api/metadata` | 表/字段白名单 | 管理员 |

## 6. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 前端框架 | React 18 + Vite 5 | 与一体化工作台统一 |
| UI 库 | Ant Design 5 | 表格/表单现成 |
| 图表（可选） | AntV G2 | 结果可视化，可后置 |
| 部署 | 打包静态资源，Nginx 反代后端 | 同源，免 CORS |

> 若只求演示，可降级为「极简 HTML + fetch」，功能页不变。简历口径仍以 React 为准。

---

## 7. 与 Agent 的关系

- 问数页是 Agent 的**唯一对外入口**，后端只认 IR、只走只读账号，前端拿不到 SQL 拼写能力。
- 指标管理页 = 业务自助定义口径（F-01 指标层落地）。
- 闸门配置页 = 管理员调安全阈值（F-04 v1.1 落地）。
